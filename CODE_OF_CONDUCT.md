# Code of conduct

Lumen follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, criticise ideas rather than people,
and keep discussions about the project. Harassment of any kind is not
tolerated.

To report a problem, open a private report through
[GitHub's private vulnerability reporting](https://github.com/Osmait/lumen/security/advisories/new)
or contact the maintainer, [@Osmait](https://github.com/Osmait), through
GitHub. Reports are kept confidential.
